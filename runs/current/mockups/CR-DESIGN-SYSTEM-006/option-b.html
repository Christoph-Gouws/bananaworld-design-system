3 · And it has to be repeated everywhere

Every line, every grid, every new column added laterongoing

The instruction lives on each box, so every grid we ever tidy this way carries six or seven copies of the same sentence, and every column added afterwards is a fresh chance to forget one. It is not wrong, it is just work that never finishes.

Where this lands

It reaches the same picture as Option A when it is done perfectly, and it fails quietly when it is not.

  • Simplest possible setting — one box, one answer, nothing clever.
  • No shortcut for a line that wants the same answer everywhere.
  • The failure is invisible — a missed box looks exactly like the problem we are fixing, and nothing flags it.
