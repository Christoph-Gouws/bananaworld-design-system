  • Shortest instruction of the three — one sentence for a whole grid.
  • No exceptions at all, including the small controls that read better centred.
  • Pushes us back to hand-built screens the moment one box needs to differ — which is how the depot system's own order screen ended up hand-built in the first place.
Where it lands: perfect on the order screen, blunt everywhere else, and the first awkward grid escapes the shared kit again.

The same for all three

Nothing changes on any screen when this is done. The setting is off unless a screen asks for it, so every existing list in every system stays exactly as it is today — and that will be proved by measurement, not asserted.

The customer system's order screen actually switching over is a separate piece of work in that system's own lane, once this is in place and that system chooses to pick it up. This change only makes the setting exist.
