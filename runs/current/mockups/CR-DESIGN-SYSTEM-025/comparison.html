The shared bar chart — pick a look

One small bar chart for every app, starting with the packhouse end-of-shift screen (class split, size split, packaging groups). Each option shows the same figures: a normal day, a shift with nothing packed yet, and a dark look. Packhouse teal is shown; every other app gets its own colour.

In every option: the orange line is "Not mapped yet" — its name says so and the colour only backs it up. A screen reader reads each line as name, amount and share, and the total last. The screen hands the chart its own figures, so the chart always matches the packout table to the last decimal.
