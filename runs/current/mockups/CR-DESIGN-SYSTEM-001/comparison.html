Which colour block do you prefer?

The receiving screen needs a row of tappable buttons for the banana colour stage, so a receiver in gloves picks one in a single tap. The button shape is already settled — a colour block next to the short code, never text printed on the colour. The only question here is what the colour block looks like. Each column shows the same seven stages, first as they appear on the tablet, then on a desk browser.

Hovering a button on a desk browser shows the full stage name; on either screen, someone using a screen reader hears the full name rather than just the code.

Colours shown are illustrative examples of the stage colours set in the master list; the buttons always show whatever is configured there, and nothing is ever printed on top of a colour. Two stages are drawn as a blend of two colours (CS3 and CS7) to show how a two-tone stage looks. One button in each browser row is drawn as already chosen, and one greyed out, so every state can be judged. If you do not pick, the work proceeds with Option A.
