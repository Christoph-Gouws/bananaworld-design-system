The short line sits under the box in exactly the place, size and colour that “Not numbered yet” and “Given automatically” already use on the document number box. Nothing new is drawn — an existing line is simply made available to a second box. The app writes the words; the shared strip never invents them.

The trade

  • For it: an app with genuinely nothing for that box says so, instead of shipping a dash that reads like somebody forgot.
  • For it: the date box on the left already works exactly this way, so it is a pattern the strip has rather than a new idea.
  • Against it: nobody has asked for it. The stuck change needs a word. Adding a setting in case it is wanted later is the habit this strip has twice refused before.

Pick this if you already know the customer system wants to explain the blank. It costs about ten minutes more than option A and stays just as safe.
