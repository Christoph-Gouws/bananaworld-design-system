Why this is the recommendation

It is the smallest possible change and it copies a pattern the strip already has.

  • Nothing moves. Four boxes, same order, so the document number stays in the top-right corner — your ruling of 8 August.
  • Nothing new to look at. The empty look already exists and is already tested.
  • The depot system is untouched — not one of its forms changes by a pixel.

The honest cost: an app with genuinely nothing for that box ships a permanently faint dashed box. That is a plain statement, not a discovery — option C below exists precisely to answer it if you would rather explain the dash.
