The word over the second box

Every form in the depot system carries the same strip of four boxes. The second box has “DC” printed over it, and that word is fixed in the shared kit — which is why the customer system’s change has been stuck since 18 August. This change lets each app print its own word over that box, the same way each form already chooses whether the first box says “Date”, “Order date” or “Run date”.

All three options below do that. They differ on one question only: what an app shows when it has nothing at all to put in that box.

One thing worth knowing whichever you pick

There is a safety check inside the depot system that reads the exact wording of the shared file, character for character. All three options leave that wording alone on purpose, so nothing breaks today and nothing breaks when the depot system next moves across — with one exception: a single line in that check will need updating at that point. It is written down now so it is not a surprise in six weeks’ time.
