A filter that can hold several choices

Today a filter across the top of a busy list holds one choice — pick a second and it replaces the first. This adds a second style that holds several: two rooms, three depots. Every list that wants one choice keeps exactly the control it has now.

All three work the same way when open. Pick how one should read when it is closed.

  • ✗Never names a choice — even one depot reads as “1 of 7”, which is less than the control says today.

A tick beside each choice. The list stays open while several are ticked — that is the whole point. “All depots” at the top is both the untouched state and the clear-everything: tick it and the rest empty.

Tabreaches the filter — one stop, like every other control in the row
Enter ↓opens the list
↑ ↓move between choices; typing a letter jumps to it
Spaceticks or unticks — and the list stays open
Esccloses and puts focus back on the filter

Nothing changes yet  The eleven lists that use these filters today keep exactly the control they have now, whichever option you pick. A list gains the new style only when its own team asks for it, in its own separate piece of work.

Deliberately not included: no searching inside the list of choices, no grouping, no “pick everything matching”. No change to the search box or the date filter.
