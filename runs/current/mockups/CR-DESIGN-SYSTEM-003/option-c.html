The open list is identical in all three options. The tags are not individually removable — a small × on each would put extra buttons inside the control’s single keyboard stop, which is the sort of thing that quietly breaks tabbing. Unticking happens in the list, where it already works.

The keyboard path — identical in all three options

Tabreaches the filter — one stop, like every other control in the row
Enter Space ↓opens the list, focus lands on the first item
↑ ↓move between choices; typing a letter jumps to it
Spaceticks or unticks — and the list stays open
Esccloses and puts focus back on the filter

Provided by the same Radix menu the row-actions “⋯” already uses, so a screen reader announces each row as a checkbox with its ticked state. Nothing here is hand-rolled.
