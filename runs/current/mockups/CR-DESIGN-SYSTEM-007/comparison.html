Which instruction wins — the whole line, or the one box?

CR-DESIGN-SYSTEM-007 · the same order line, drawn three ways. Everything else on the screen is identical.

The situation. A whole line of fields has been told “line up along the top”. One box in that line — the buttons — was separately told by its author to sit in the middle, using the older way of saying it (which was the only way, until last week).

The question. When those two instructions disagree, which one should the shared kit obey? The highlighted box in each version is the only thing that moves.

Recommended

My recommendation: A. It is the smallest of the three, it is what was already agreed, and it is the only one where the screen ends up looking the way its author asked. Choosing it now costs nothing, because no app has picked up the line instruction yet — the same fix after an app adopts would move things people are already looking at.
